# Simple Blog App

This is a simple blog application built with React. It allows users to view a list of blog posts and learn more about the blog and its author.

## Features

- **Home Page**: Displays a list of blog posts.
- **About Page**: Provides information about the blog and the author.
- **Responsive Design**: The application is styled to be responsive and user-friendly.

## Installation

1. Clone the repository:
   ```
   git clone https://github.com/yourusername/simple-blog-app.git
   ```
2. Navigate to the project directory:
   ```
   cd simple-blog-app
   ```
3. Install the dependencies:
   ```
   npm install
   ```

## Usage

To start the application, run:
```
npm start
```
This will launch the app in your default web browser.
